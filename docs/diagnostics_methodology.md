# Diagnostics methodology

Phase 2 compares source feature distributions, missingness, source-specific
performance, and reliability using the preserved first-study predictions.
Numeric shift is summarised with means, standard deviations, medians,
interquartile ranges, and standardised mean differences. Categorical shift is
summarised with proportions, absolute differences, and Jensen–Shannon
divergence.

Reliability diagnostics include probability distributions, ROC/PR metrics,
calibration bins, Brier scores, prevalence-only Brier references, and
prevalence PR baselines. A complete-case analysis is reported only as a
sensitivity analysis and does not replace the imputation-based primary study.

Source differences are descriptive. Population, measurement, missingness,
and label processes are confounded, so the diagnostics do not establish
causation or clinical validity.
