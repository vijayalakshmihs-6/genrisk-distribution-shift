# Dataset provenance

The experiment uses the official UCI Machine Learning Repository Heart
Disease collection. The preserved archive is `data/raw/uci_heart_disease/heart+disease.zip`.
It contains the Cleveland, Hungary, Switzerland, and Long Beach VA source
files. The UCI documentation describes the data as a heart-disease
classification collection with 76 original attributes, while this study uses
the explicitly documented seven-feature representation and binary target.

The archive checksum is recorded in `data/raw/uci_heart_disease/checksums.sha256`
and was verified as:

`b17cd273da9ce1caa4710fce80227ea454d4dbf9fcbc8e6a9121672751563adc`

Official source: <https://archive.ics.uci.edu/dataset/45/heart%2Bdisease>

The preserved audit records the dataset licence as **CC BY 4.0** and the DOI
as `10.24432/C52P4X`. Cite the UCI repository and the original dataset
contributors when publishing. This repository preserves provenance and
checksums; it does not claim ownership of the dataset.
